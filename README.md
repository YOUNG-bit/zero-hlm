# Zero-HLM Project Page

[Website](https://young-bit.github.io/zero-hlm/) · [MIT code license](LICENSE)

Static HTML, CSS and JavaScript in `site/`.

## Reuse this template

Choose **Use this template** and replace the page content and media with your own.

```sh
python3 -m http.server 8000 --directory site
```

Open `http://localhost:8000/`. To publish, select **Settings → Pages → GitHub Actions** and push to `main`.

See [TEMPLATE.md](TEMPLATE.md) for the file map.

Design inspiration: [VLK](https://vision-language-kinematics.github.io/) and [WANDA](https://wanda.lecar-lab.org/).
